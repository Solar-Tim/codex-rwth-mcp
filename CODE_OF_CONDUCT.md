# Code of Conduct

This project uses a simple contribution standard:

- Be respectful and constructive.
- Assume good intent, but be precise when discussing technical problems.
- Do not share other people's private code, credentials, screenshots, or logs.
- Keep issues and pull requests focused on the project.
- Do not present this repository as an official provider, RWTH, KI:connect, or
  university service.

Maintainers may close or remove comments, issues, or pull requests that violate
these expectations.
